På den här sidan kan du se de gallringsbekräftelser som har skapats för detta arkiv. En gallringsbekräftelse innehåller en rapport som samlar de strukturenheterna och extra metadatainformation. För att gallra den strukturenhet som är associerad med gallringsbekräftelsen, måste du explicit utföra gallringsåtgärden. Efter gallring kan den strukturenheten antingen återställas eller tas bort permanent.
