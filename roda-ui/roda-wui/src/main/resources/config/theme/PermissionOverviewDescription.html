The permission overview shows how permissions are distributed in ETERNA: which permissions each group holds (Permissions per group), which groups and effective permissions each user has (Users), which groups and users may read, update, create, delete and grant on fonds, classes and series (Structural units), and which access rules are active (Access rules). The page is read-only; changes are made under "Users and groups" and on each structural unit.

In ETERNA permissions are assigned to groups. What is often called a "role" in requirements therefore corresponds to a group in ETERNA, and a user's effective permissions are the union of the permissions of the user's groups and any permissions assigned directly to the user.

The button Report (HTML) opens a printable report with the same content in a new window (print or save as PDF from the browser). The button CSV downloads the same data as a comma-separated file for further processing, for example in Excel.
