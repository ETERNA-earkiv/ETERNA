På den här sidan kan du se de förvaringsenheter där gallringsfristen har förfallit eller de förvaringsenheter som är redo för granskning. Om den förvaringsenheten är redo för gallring kan gallringen genomföras. Alternativt kan man göra en justering i gallringsschemat. Om den förvaringsenheten är redo för granskning kan man endast ändra i gallringsschemat. Det är också möjligt att se de förvaringsenheter där uträkningen av gallringsfristen har misslyckats.
