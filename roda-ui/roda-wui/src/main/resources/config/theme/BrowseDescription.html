The catalogue is the inventory of all items or records found in the repository. A record can represent any information entity available in the repository (e.g. book, electronic document, image, database export, etc.). Records are typically aggregated in collections (or fonds) and subsequently organised in subcollections, sections, series, files, etc. This page lists all the top-level aggregations in the repository. You may drill-down to sub-aggregations by clicking on any of the items in the table below.

On the left side, a catalogue tree provides a quick overview of the archive structure. Click any level in the tree to navigate directly to it. Use the arrow next to a level to expand or collapse its sub-levels. You can also filter the tree using the search box at the top — type part of a name to quickly find the right level. The tree automatically synchronises with the selected level as you navigate the archive.
