Open-Source Digital Repository Designed for Preservation

ETERNA (Repository of Authentic Digital Records) is a long-term digital repository solution that delivers functionalities for all the main functional units of the OAIS reference model.

ETERNA is capable of ingesting, managing, and providing access to various types of digital content produced by large corporations and public bodies. ETERNA was developed using open-source technologies, and it's supported by the following standards:

OAIS
Open Archival Information System
EAD
Encoded Archival Description
METS
Metadata Encoding and Transmission Standard
DC
Dublin Core
PREMIS
Preservation metadata
E-ARK IP
eArchiving standards for SIP, AIP and DIP packages

Authenticity

ETERNA uses PREMIS preservation metadata to create a trust chain between all generations of digital assets.

Preservation metadata, together with the establishment of trust of its surrounding environment (ISO 16363 and ISO 14721) ensures that the repository service is reliable, and digital assets remain authentic over time.

ETERNA also supports plugins that assess the validity of digital signatures and re-sign archived PDFs when the lifetime of digital signatures is coming to an end.

Vendor independent

ETERNA is built on top of enduring open-source technologies.

The entire infrastructure required to support ETERNA is also vendor independent. This means that you may use the hardware and the Linux distribution that best fit your institutional needs.

Because the product itself is open source, you don't have to rely on a single vendor for support. The entire source code of the system is available on GitHub for inspection.

Standards conformance

ETERNA is compliant with several open descriptive metadata standards such as EAD, and Dublin Core, PREMIS for preservation metadata and METS for structural metadata.

Preservation actions

Preservation actions can be executed right from the user interface over any selection of digital objects in the repository.

Retention and disposal

ETERNA incorporates robust and comprehensive functionality for the definition and implementation of retention and disposal policies.

Scalability

ETERNA is ideal for large organisations with millions of digital objects. It's service-oriented nature allows it to be highly scalable, enabling the distribution of load between several servers.

Ingest workflows

Ingest workflows can be customised by the user to implement institutional policies and handle special collections of data. Ingest workflows can be enhanced via the use of open source or commercial plugins.

Adaptability

The pluggable architecture of ETERNA makes it easy to add more functionality to the system without affecting its core functionality.
