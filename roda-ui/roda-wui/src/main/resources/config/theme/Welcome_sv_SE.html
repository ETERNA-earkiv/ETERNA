Om systemet

ETERNA är ett e-arkivsystem för långsiktigt digitalt bevarande, utvecklat av WhiteRed som en öppen svensk anpassning av RODA.

Systemet följer internationella standarder för arkivering — OAIS, E-ARK, FGS, PREMIS och METS — och stödjer hela bevarandekedjan från leverans till tillhandahållande.

Arkivet uppfyller

  • OAIS — ISO 14721
  • E-ARK CSIP 2.2
  • FGS 2.1
  • PREMIS 3.0
  • METS 1.12
  • EAD 3
