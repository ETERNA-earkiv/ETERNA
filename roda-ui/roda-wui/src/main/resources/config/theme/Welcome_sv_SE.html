Öppen källkod digitalt arkiv för långtidsbevarande

ETERNA är en lösning för långtidsbevarande av digital information som tillhandahåller funktioner för alla huvuddelar i OAIS-referensmodellen.

ETERNA kan importera, hantera och ge tillgång till olika typer av digitalt innehåll som produceras av stora organisationer och myndigheter. ETERNA är utvecklat med öppen källkod och bygger på följande standarder:

OAIS
Open Archival Information System
EAD
Kodad arkivbeskrivning
METS
Standard för metadata och överföring
DC
Dublin Core
PREMIS
Metadata för bevarande
E-ARK IP
eArkivering-standarder för SIP, AIP och DIP-paket

Äkthet

ETERNA använder PREMIS-metadata för bevarande för att skapa en förtroendekedja genom alla generationer av digitala objekt.

Bevarandemetadata och tillit till miljön (ISO 16363 och ISO 14721) säkerställer att arkivtjänsten är pålitlig och att digitala objekt förblir autentiska över tid.

ETERNA stöder även tillägg för att kontrollera giltigheten av digitala signaturer och kan om-signera arkiverade PDF-filer när signaturernas giltighet löper ut.

Oberoende från leverantör

ETERNA bygger på robusta och beprövade öppen källkods-teknologier.

All infrastruktur som behövs för att köra ETERNA är också leverantörsoberoende. Du kan alltså välja hårdvara och Linux-distribution som passar din organisation bäst.

Eftersom produkten är öppen källkod är du inte bunden till någon leverantör för support. All källkod är tillgänglig på GitHub.

Standardföljsamhet

ETERNA följer flera öppna standarder för beskrivande metadata som EAD och Dublin Core, PREMIS för bevarandemetadata och METS för strukturmetadata.

Bevarandeåtgärder

Bevarandeåtgärder kan utföras direkt via användargränssnittet för valfritt digitalt objekt i arkivet.

Bevarande och gallring

ETERNA erbjuder robusta och heltäckande funktioner för att definiera och implementera policyer för bevarande och gallring.

Skalbarhet

ETERNA är idealiskt för stora organisationer med miljontals digitala objekt. Den tjänstebaserade arkitekturen möjliggör hög skalbarhet och belastningsfördelning över flera servrar.

Inmatningsarbetsflöden

Inmatningsarbetsflöden kan anpassas av användaren för att stödja organisationens policyer och hantera särskilda datamängder. Arbetsflöden kan utökas med öppna eller kommersiella tillägg.

Anpassningsbarhet

ETERNA:s modulära arkitektur gör det enkelt att lägga till nya funktioner utan att påverka kärnfunktionaliteten.
